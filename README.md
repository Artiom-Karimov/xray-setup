# Разворачиваем частный VLESS сервис

Ситуация: Мы уехали из офиса в другой город, другую страну. При этом нам нужно находиться в сети и иметь IP того города, где находится наш офис.

Решение: 
- Арендовать виртуальную машину (VPS, VDS) в городе назначения;
- Развернуть свой частный VLESS сервис.

Всё это мы делаем исключительно в личных целях. Делиться доступом с кем бы то ни было автор не рекомендует, но ограничений по количеству клиентов нет.

## Что вы должны уже уметь
- Подключаться к удалённой машине по SSH
- Понимать работу с терминалом linux на базовом уровне

## Шаг 1. Арендуем VPS
- Регистрируемся на сайте провайдера. Протестировано на [adminvps](https://adminvps.ru/), также подойдёт [timeweb](https://timeweb.cloud/).
- Выбираем самую дешёвую VPS и операционную систему `Debian`(не Ubuntu, потому что нам дороги ресурсы). Протестировано на тарифе `1x CPU, 1 GiB RAM, 10 GiB ROM`.
- Оплачиваем VPS на нужный нам срок, подтверждаем.
- На этом этапе мы должны получить `публичный IP адрес машины`, например 123.12.23.123. Он пригодится на следующем этапе.

## Шаг 2. Регистрируем доменное имя
Это будет адрес нашего сервиса - к примеру `my.website.ru`.

Есть 3 основных способа зарегистрировать домен:
- У провайдера нашей VPS. Часто эта функция встроена в сервис, но за неё, возможно, придётся доплатить.
- В региональном или международном регистре (тоже платно) - cloudflare.com, reg.ru.
- Бесплатно, на сайте [freedns](https://freedns.afraid.org/). В примере будем использовать этот вариант.

### Получить домен на freedns
- Идём на сайт [freedns](https://freedns.afraid.org/).
- Регистрируемся с настоящим email.
- Идём в раздел `Subdomains`, кликаем `Add`
- Type: `A`, Subdomain: `придумайте-свой`, Domain: `выберите-любой`, Destination: `IP.вашей.машины` из предыдущего шага.

На привязку домена к IP уйдёт некоторое время. Обычно хватает 40-60 минут.

На этом этапе у вашей VPS есть не только IP, но и читаемый адрес.

## Шаг 5. Настраиваем клиент (своё устройство)

### Скачиваем клиент
- Переходим к релизам [V2RayN](https://github.com/2dust/v2rayN/releases).
- Прокручиваем последний пост до раздела `Assets` и находим свою ОС (типично - `v2rayN-windows-64-desktop.zip`).
- Скачиваем, распаковываем запускаем.

### Настраиваем подключение

- Configuration -> Add VLESS
- Address: `доменное.имя.из.шага.2`
- Port: `443`
- UUID: Содержимое поля `"clients"` -> `"id"` из `xray/config.json` VPS (пример: `be6142bf-0cb1-4e4a-b62c-c9817b990237`)
- Transport: `WS`
- Path: `/vlessws`
- TLS: `tls`
- SNI: `доменное.имя.из.шага.2`
- Allow Insecure: `false`

### Конфиг для смартфона

Для этого нам всё равно понадобится V2RayN на компьютере, чтобы сформировать конфиг.

Далее его можно экспортировать в виде ссылки или QR-кода (Share).

Приложение есть в [PlayStore](https://play.google.com/store/search?q=v2raytun&c=apps&hl=ru) и [AppStore](https://apps.apple.com/us/app/v2raytun/id6476628951).
